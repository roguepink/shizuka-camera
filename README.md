# しずかカメラ

シャッター音が鳴らないカメラ。寝ている赤ちゃんやペット、静かな場所での記録に。無料・広告なし・登録なし。

**使う: https://roguepink.github.io/shizuka-camera/**

## LINE で送る・ホーム画面に入れる

- 上のアドレスを LINE に貼れば、タイトルと絵つきの紹介が出る。タップするとすぐ使える
- **LINE の中で開いたときは、ホーム画面に入れられない。**メニューから「Safari で開く」(iPhone)/「他のアプリで開く」→ Chrome(Android)を選んでから入れる
  - iPhone(Safari): 共有ボタン →「ホーム画面に追加」 / Android(Chrome): メニュー(︙)→「アプリをインストール」
- 入れたあとは全画面で起動。一度開けば電波がなくても使える

## 直して公開するとき

- `main` に push すれば公開される(GitHub Pages)。電波のある人は、**次に開いたとき**に新しい版になる(`sw.js` は まずネットで最新を取りにいく)
- `sw.js` の `VERSION` を上げるのは、覚えるファイル(`FILES`)を変えたときだけ

## しくみ(なぜ音が鳴らないか)

- スマホのカメラアプリを使わず、ブラウザが見ているカメラの映像から1コマを写し取って写真にしている。音を出す命令は1つも使っていない
- 撮った写真は、まずアプリの中(IndexedDB)にしまう。「保存」で共有の画面を出し、写真アプリに入れてもらう(ブラウザのアプリは、だまって写真アプリに入れられない決まり)
- 画質は、スマホのカメラアプリより少し落ちる(映像の1コマなので)。音量ボタンでは撮れない
- 隠れて撮る使い方をさせないため、画面を暗くしたまま撮る・別のアプリのふりをする などのしかけは入れない(2026-11-08)
