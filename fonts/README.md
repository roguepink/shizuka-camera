# 日付に使う字(Google Fonts)

どのスマホでも同じ見え方にするため、字のデータをアプリの中に入れている。
日付に使う字(数字・. : ( ) ・英語の曜日の文字・日月火水木金土・ボタンの名前)だけにしぼってある。

| ファイル | 字の名前 | 太さ | 決まり |
|---|---|---|---|
| digital.woff2 | M PLUS 1 Code | 700 | SIL Open Font License 1.1 |
| maru.woff2 | Zen Maru Gothic | 700 | SIL Open Font License 1.1 |
| mincho.woff2 | Shippori Mincho | 700 | SIL Open Font License 1.1 |
| tegaki.woff2 | Klee One | 600 | SIL Open Font License 1.1 |

取り寄せ先: https://fonts.google.com/ (fonts.googleapis.com の text= で必要な字だけ、2026-11-10)。
OFL の全文: https://openfontlicense.org/open-font-license-official-text/
字をふやすとき(例: 新しい曜日の書き方)は、同じしかたで取り寄せ直す。
